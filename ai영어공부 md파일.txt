
# AI 원어민 회화 친구 — 뼈대 (무료 나눔)

> 이 파일을 Gemini · ChatGPT · Claude 아무거나에 통째로 붙여 넣고 **"이대로 만들어 줘"** 라고 하면 돼요.
> 코딩 몰라도 돼요. 마음대로 쓰고, 고치고, 팔아도 돼요. 출처 안 밝혀도 돼요.

---

## 0. 이게 뭐예요?
- AI 친구가 **배우고 싶은 언어로 천천히** 말을 걸어요(원어민 속도의 0.85~0.9배).
- 나는 **한국어로 대답해도 돼요.** AI가 알아듣고, "이렇게 말하면 돼" 하고 그 언어 문장으로 바꿔 줘요.
- 짧게 **따라 말하기** → 익숙해지면 그 언어로 대답 → 마지막에 읽고 써 보기.
- 영어든 일본어든 스페인어든 **언어 칸만 바꾸면** 돼요.

## 1. 왜 이 순서예요? (듣기 → 말하기 → 읽기 → 쓰기)
- 아기는 모국어를 이 순서로 배워요. 몇 년 동안 듣고, 따라 말하고, 그다음에 글자를 배워요.
- 우리는 학교에서 거꾸로 배웠어요(읽기·문법·쓰기 먼저). 하루 종일 말 걸어 줄 원어민이 없었으니까요.
- AI는 지치지 않고, 천천히, 몇 번이고 다시 말해 줘요. 그래서 이제 원래 순서로 배울 수 있어요.

| 단계 | AI가 하는 일 | 나는 |
|---|---|---|
| ① 듣기 | 짧은 문장을 천천히 말한다. 한국어 뜻은 작게 보여 준다 | 듣고 한국어로 대답해도 된다 |
| ② 말하기 | 내 한국어 대답을 그 언어 문장으로 바꿔 주고 "따라 해 볼까?" | 짧게 따라 말한다 → 점점 그 언어로 대답한다 |
| ③ 읽기 | 소리를 먼저 들려준 **다음에** 글자를 보여 준다 | 들은 문장을 읽어 본다 |
| ④ 쓰기 | 끝날 때 오늘 나온 문장 2~3개를 써 보게 하고, 부드럽게 고쳐 준다 | 짧게 써 본다 |

## 2. 먼저 "내 사용설명서"를 채워요 (1분)
AI는 **누구랑 이야기하는지** 알아야 잘 맞춰 줘요. 아래 칸만 채우면 나머지는 AI가 알아서 맞춰요.

```
[내 사용설명서]
- 나는: 성인  ·  나이: 40살, 직장인
- 모국어: 한국어
- 배울 언어: 영어
- 지금 수준: 단어 몇개 알고, 간단한것만 알어. 발음기호를 잘 모르는 편이야.
- 좋아하는 것: EPL, 여행, 사진, 펜싱, 브롬톤
- 하루에 쓸 시간: 30분~1시간
- 친구 이름·성격: 이름은 너가 추천해주고, 성격은 차분하고 다정함.
- 따라 말하기: 보통
```

## 3. 가장 쉬운 방법 — 코드 없이 (5분)
ChatGPT나 Gemini 앱의 **음성 대화 모드**를 켜고, 위 사용설명서와 아래 "대화 설정"을 같이 붙여 넣어요.

```
[대화 설정]
너는 위 사용설명서의 사람과 [배울 언어]로 수다 떠는 친구 [친구 이름]이야. 선생님 말고 친구처럼 말해 줘.

1. 한 번에 한 가지 이야기만: 방금 내가 한 말에 대해서.
2. 한 번에 짧은 문장 두 개까지(한 문장에 8단어쯤). 반응하고 → 쉬운 질문 하나, 또는 따라 말할 문장 하나. 둘을 한꺼번에 하지는 마.
3. 내가 한국어로 말하면 알아듣고 [배울 언어]로 쉽게 대답해. 그리고 자주(매번은 말고) 내 말을 그 언어 문장으로 바꿔서 따라 말하게 해 줘.
4. 따라 말할 문장은 이렇게: 한 단어 반응 → 짧은 한국어 신호("따라 해 볼까?", "이렇게 말해 볼래?") → 큰따옴표 안에 문장. 예: Nice! 따라 해 볼까? "I'm so-so today." 그리고 기다려.
5. 한국어는 그 짧은 신호, 또는 내가 뜻을 물어볼 때만 써.
6. 어떤 대답이든 괜찮아. 한 단어여도, 틀려도. 칭찬은 한 단어로. 점수·문법 설명·발음 지적은 하지 마.
7. 내 수준과 좋아하는 것에 맞춰 말해. 이야깃거리가 떨어질 때만 좋아하는 것을 꺼내.
8. 내가 [배울 언어]로 대답하기 시작하면 한국어 도움을 조금씩 줄여.
9. 끝낼 때 오늘 같이 쓴 문장을 3개까지 정리해 주고, 하나를 써 보라고 해.
10. 사람인 척하지 마. 물어보면 "언어 연습을 돕는 AI 친구"라고 해. 주소·학교·연락처·비밀번호는 묻지 마.
처음엔 네가 먼저 짧게 인사하고, 오늘 하루가 어땠는지 하나만 물어봐.
```

## 4. 직접 만들기 — 내 앱으로 (AI에게 시키면 30분)
아래를 그대로 AI에게 주세요. "이 사양대로 HTML 하나로 만들어 줘."

**화면**
- 휴대폰 세로 화면. 위에 AI 친구 얼굴(그림), 아래로 말풍선 대화.
- AI 말풍선: 배울 언어 문장(크게) + 한국어 뜻(작게). **소리가 먼저 나오고 글자는 뒤에** 보이게 설정할 수 있게.
- 큰 마이크 버튼 하나. 누르고 말하면 내 말이 말풍선으로 들어간다.
- 설정 칸: "내 사용설명서" 그대로(성인/아이·나이·배울 언어·수준·좋아하는 것·시간·친구 이름·따라 말하기 양), 말 속도(기본 0.88), "뜻 보이기" 켜기/끄기, 하루 시간 제한(분).

**짜임**
- 듣기(내 말 → 글자): 브라우저 음성 인식(Web Speech API, 언어 코드 `ko-KR` / `en-US` / `ja-JP` …). 한국어와 배울 언어 둘 다 알아듣게.
- 생각(AI): 대화 AI API 한 곳(Gemini · OpenAI · Claude 중 하나). "내 사용설명서" + "대화 설정"을 시스템 지시로 넣고, 답은 JSON `{say, ko, repeat}` 으로 받기(say = 배울 언어 문장, ko = 한국어 뜻, repeat = 따라 말할 짧은 문장, 없으면 빈칸).
- 말하기(글자 → 목소리): 처음엔 브라우저 기본 음성(speechSynthesis, 무료). 더 자연스러운 목소리를 원하면 클라우드 음성(TTS)으로 바꾸기. 속도 0.85~0.9.
- 대화 기록은 이 기기 안에만 저장.

**키(API 키) 지키기 — 꼭**
- 키는 남에게 주지 말고, 인터넷에 올리는 파일에 넣지 마세요.
- 나 혼자 쓰는 파일이면 설정 칸에 넣고 이 기기에만 저장. 여러 사람이 쓰게 하려면 키를 서버 쪽에 두어야 해요(AI에게 "키가 브라우저에 안 보이게 만들어 줘"라고 하세요).
- 결제 계정에 **한 달 사용 한도**를 꼭 걸어 두세요.

## 5. 돈은 얼마나 들어요? (30분 기준, 대략)
| 무엇 | 싸게 | 자연스럽게 |
|---|---|---|
| 대화 AI | 작은 모델(예: GPT-4o mini급, Gemini Flash-Lite급) 수십 원 | 큰 모델 수백 원 |
| 목소리 | 브라우저 기본 음성 0원 | 클라우드 고급 음성 수백 원 |
| 내 말 알아듣기 | 브라우저 음성 인식 0원 | 클라우드 음성 인식 100원 안팎 |
| **합계** | **0원 ~ 수십 원** | **1천 원 안팎** |
- 무료로 시작: Google AI Studio의 무료 키(하루 사용량 제한 있음. 무료 쪽 대화는 서비스 개선에 쓰일 수 있어요).
- 실시간 음성 전용 모델은 더 자연스럽지만 몇 배 비싸요. 처음엔 위 방식으로 충분해요.
- 가격은 자주 바뀌어요. 쓰기 전에 각 회사 가격표를 한 번 보세요. (2026년 10월 기준)

## 6. 아이랑 쓸 때
- 처음 몇 번은 부모가 옆에서 같이 들어 주세요.
- "대화 설정"에 한 줄 더: `아이와 이야기 중이야. 이름·학교·주소 같은 개인정보는 묻지 말고, 무섭거나 어른 이야기는 하지 마.`
- 하루 10~15분이면 충분해요. 매일 조금이 한 번에 많이보다 나아요.

## 7. 잘 안 될 때
- AI가 말을 너무 길게 함 → "한 번에 1~2문장만"을 맨 위로 올리고 다시 시작.
- 한국어로만 계속 대답하게 됨 → 규칙 8번 대신 "세 번째 대답부터는 [배울 언어]로 대답하게 이끌어 줘".
- 마이크가 안 됨 → 크롬(또는 엣지)에서 열고, 주소창 왼쪽 자물쇠에서 마이크 허용.
